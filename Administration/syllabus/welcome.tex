\section*{Welcome and Overview}
Welcome to Object-Oriented Software Development! 
We are Ian and Aaron (a.k.a.\ Profs.\ Ludden \& Wilkin), and 
we'll be your instructors. 
Before we get into details, 
here's a quick overview. 
% In previous programming courses, 
% you should have learned how to solve problems using code, 
% such as writing a small Python function or script. 
In CSSE 220, 
we will build on your foundational programming skills  
by exploring object-oriented design principles 
and other software engineering practices. 
We will use Java, 
a widely-used object-oriented programming language, 
to apply these concepts. 
If you continue on to other CSSE courses, 
this course will help you start thinking about 
the bigger picture of software development. 
If this is your last CSSE course, 
it will position you to write readable, maintainable code 
to support projects in your primary field.

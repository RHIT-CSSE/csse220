\section*{Final Project}
The course ends with a group project designed to 
integrate the concepts and skills learned throughout the course. 
This project will require collaboration, creativity, and critical thinking 
as you work in a team of 2--4 students to develop 
an object-oriented software application. 
Detailed guidelines and expectations for the final project 
will be provided in a separate document.  
Each project will earn one of four grades:   
Poor, Satisfactory, Good, or Excellent. 
Project application domains will vary, 
but every project must include the following features:
\begin{itemize}[noitemsep,nolistsep]
\item File I/O with custom exception handling. 
\item A Java Swing GUI with event-based programming. 
\item Inheritance and interfaces with polymorphism. 
\item JUnit tests. 
\item Design analysis in terms of object-oriented design principles. 
\item Appropriate data structures, such as ArrayLists or HashMaps. 
\item A presentation during the last week of class. 
\end{itemize}
